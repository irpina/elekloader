      Get started

      Custom firmware for your Elektron box

      New machines and features for the Digitakt, Digitone and Octatrack, built here in your browser from Elektron's own OS file. You flash the result like any OS update.

      • Nothing is uploaded: it all happens in this tab
      • Only the main OS changes, so the stock OS always takes it back
      • Free and open source

      1. 1Pick your device

      2. 2Add its stock OS file

      3. 3Add mods, then build

        Press + Add on the mods you want, below. Then Build makes your custom OS: a .syx you send with Elektron Transfer, like any update. How to flash, and how to go back

        About elekloader

        Nothing is uploaded. Your stock OS file and your mods stay in this browser tab; the build runs here, in Python compiled to WebAssembly. No firmware is hosted on this site: you bring Elektron's file. elekloader is an independent project, not affiliated with, endorsed by or supported by Elektron, and flashing custom firmware is at your own risk.
